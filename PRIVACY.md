# Convert privacy policy

Convert 1.0.0 converts files on this device. Convert does not collect data.

Files are converted locally. A file you choose in the Convert window is read on this device and the result is saved on this device. Convert does not run analytics and does not upload the file to a Convert server.

The only network request is in the browser extension. When you choose Convert to on a link or image, the extension reads that http or https address so the conversion can run locally. Other protocols are rejected. Offer settings stay in the browser's local storage.

The Windows app does not contact the network to convert a file. Its runtime is included in the installer.
